# Claude 컨텍스트 동기화 규칙 (claude.md)

1. 사용자의 요청에 따라 코드를 수정하거나 주요 작업(기능 추가, 버그 수정 등)을 완료할 때마다, 즉시 `claude.md` 파일을 최신 상태로 업데이트해야 합니다.
2. `claude.md` 파일에는 다음 내용이 포함되어야 합니다:
   - 현재 진행 중인 프로젝트 및 시스템의 개요
   - 방금 완료한 최신 작업 내역 및 수정된 파일
   - 현재 데이터베이스 스키마 구조 (간략히)
   - 향후 진행할 다음 단계 (Next Steps)
3. 이 규칙은 다른 AI 에이전트(예: Claude)가 현재 상황을 완벽하게 파악하고 이어서 작업할 수 있도록 돕기 위해 존재합니다. 매 작업 사이클의 마지막 툴 호출 시 반드시 `claude.md` 파일 업데이트를 잊지 마세요.
