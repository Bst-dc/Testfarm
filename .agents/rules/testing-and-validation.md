# 꼼꼼한 테스트 및 오류 검증 (Strict Testing and Validation)

사용자의 지시나 아이디어를 실행하여 코드를 작성 및 수정할 때, 다음의 절차를 반드시 지켜야 합니다:

1. **테스트 우선 (Test First)**: 코드를 수정한 후에는 즉시 화면이나 파일에 적용만 하고 끝내지 마세요. 스크립트 실행, 더미 데이터 테스트 등을 통해 문법 오류나 실행 오류가 없는지 직접 확인해야 합니다.
2. **오류 수정 루프 (Fix and Retest)**: 테스트 도중 오류가 발견되면 원인을 찾아 코드를 수정하고 **다시 테스트**합니다.
3. **오류가 없을 때만 최종 적용 (Apply Only When Error-Free)**: 여러 번의 테스트 끝에 완벽히 동작하고 오류가 없음을 확인한 경우에만 최종적으로 소스 코드에 반영하고 커밋(또는 확정)합니다.
4. **결과 보고**: 사용자에게 적용 결과와 함께 "어떤 테스트를 거쳐 오류가 없음을 확인했는지"를 보고합니다.
